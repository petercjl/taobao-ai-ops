# Knowledge Layer Schema

This is a small, routed knowledge layer for the Step 5 category-opportunity judgment. At Step 5, read this file, `index.md`, recent `log.md`, the matching query entry, and its required topic page. Do not load this layer during database checks or collection. `source-manifest.md` is maintenance provenance and is not an ordinary runtime read.

Source classes: `U` user-confirmed method, `W` compiled traceable domain knowledge, `E` verified execution evidence, `A` provisional Agent hypothesis.
